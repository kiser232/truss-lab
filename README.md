# 장원준 수능 응원 갤러리

2027학년도 대학수학능력시험(2026년 11월 19일 목요일)을 앞둔 장원준을 응원하는 게시판입니다. 글 목록, 글쓰기, 수정, 삭제, 댓글, 추천, 검색을 쓸 수 있습니다.

시험까지 남은 날은 한국 시간 기준으로 계산합니다. 성적 통지일은 2026년 12월 11일입니다.

## 로컬에서 실행

```bash
npm install
npm test
npm run dev
```

개발 서버 주소는 터미널에 표시됩니다. 이 저장소의 실행 예시는 `http://127.0.0.1:43123` 입니다.

```bash
npm run dev -- -p 43123
```

프로덕션 모드:

```bash
npm run build
npm start -- -H 0.0.0.0 -p 43123
```

## 글은 어디에 저장되나

`data/board.json` 파일이 게시판 전체입니다. 비밀번호는 평문으로 저장하지 않고 scrypt 해시만 저장합니다. 처음 포함된 글의 비밀번호는 저장소에 없어서 수정하거나 삭제할 수 없습니다. 직접 쓴 글은 작성할 때 입력한 비밀번호로 수정하고 삭제합니다.

추천은 브라우저 쿠키 하나당 한 표입니다. 같은 버튼을 다시 누르면 추천이 취소됩니다.

## Docker로 호스팅

글이 파일에 남으려면 디스크가 유지되는 Node 서버가 필요합니다. 서버리스 정적 호스팅에 올리면 글을 다시 시작할 때마다 처음 상태로 돌아갑니다.

```bash
docker build -t wonjun-gallery .
docker run --rm -p 43123:43123 -v wonjun-gallery-data:/app/data wonjun-gallery
```

볼륨을 붙이면 컨테이너를 지워도 글이 남습니다. 볼륨이 비어 있으면 이미지 안의 초기 게시판을 복사해서 시작합니다.
