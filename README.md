# 트러스 실습실

건축공학과 학생을 위한 평면 트러스 교육 웹앱입니다. 계산기, 실습, 퀴즈 세 화면으로 구성되어 있습니다.

격자 한 칸은 1m이고 힘의 단위는 N입니다. 교육용 모형 스케일이라 실제 구조물 하중과는 크기가 다릅니다. 부재 단면이 정해져 있어 **허용축력(N)** 과 비교합니다. 실무에서는 응력 σ = N / A 를 허용응력과 비교합니다.

## 화면

1. **트러스 계산기** — 격자 또는 좌표로 절점을 놓고 부재를 잇습니다. 재료마다 인장·압축 허용축력이 다릅니다. 돌과 상자는 절점에만 올리고, 자동차는 지정한 절점 경로를 따라 움직이며 인접한 두 절점에만 하중을 나눕니다. 허용을 넘기면 그 부재가 파괴되고, 견디면 마우스를 올린 부재의 축력이 보입니다.
2. **실습** — 단계마다 예산이 있습니다. 나무, 케이블, 콘크리트처럼 인장과 압축 능력이 다른 재료로 미션을 통과해야 합니다. 판정은 정정 트러스면 절점법, 부정정이면 직접강성법입니다. 시험이 끝나면 반력과 절점 평형 해설이 나옵니다.
3. **퀴즈** — 재료 카드 분류, 와렌·하우·프랫·킹포스트·퀸포스트 속독, 주어진 트러스에서 인장 또는 압축 부재를 모두 고르는 문제가 무작위로 이어집니다. 해설 후 다음 문제가 자동으로 나옵니다.

인장(+)은 부재가 절점을 당기는 힘, 압축(−)은 미는 힘입니다. 평면 트러스의 정정 조건은 `m + r = 2j` 입니다.

## 로컬 실행

```bash
npm install
npm test
npm run dev
```

정적 사이트로 빌드한 뒤 확인하려면:

```bash
npm run build
npx serve out -l 43123
```

## Docker

```bash
docker build -t truss-lab .
docker run --rm -p 43123:43123 truss-lab
```

## GitHub Pages

`main`에 푸시하면 `.github/workflows/pages.yml`이 `out` 폴더를 GitHub Pages로 배포합니다. 저장소 설정에서 Pages 원본을 **GitHub Actions**로 한 번 지정해야 합니다. 프로젝트 페이지(`username.github.io/저장소이름`)는 빌드할 때 저장소 이름을 base path로 넣습니다. 사용자 페이지(`username.github.io`)는 루트에 배포됩니다.
