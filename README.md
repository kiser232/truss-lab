# 트러스 랩

건축구조 수업용 트러스 실습실입니다. 절점을 이어 부재를 만들고, 절점법으로 축력과 반력을 확인합니다. 실습에서는 자재 단가와 예산 안에서 단계별 트러스를 설계합니다.

## 화면

- **계산기** — 평면과 3D. 격자를 누르거나 x, y 좌표를 입력해 절점을 둡니다. 핀과 롤러에 커서를 올리면 회전이 나오고, 롤러를 돌리면 바닥 롤러와 가로 롤러가 바뀝니다. 휠이나 +/−로 확대하면 격자 간격이 0.5m에서 0.25m, 0.1m, 0.05m로 줄어듭니다. 빈 곳을 끌면 더 넓은 바닥으로 이동하고, 3D에서는 바닥을 끌어 회전합니다.
- **실습** — 예산 안의 8단계. 자재마다 m당 비용이 보이고, 시험 뒤 절점법 순서가 나옵니다. `예시 풀이`에 문제의 답이 있습니다.
- **퀴즈** — 절점법 숫자, 자재 분류, 짧은 개념. 틀린 문제는 오답노트에 모입니다.
- **기출** — 2019–2024 원본 PDF와, 그중 트러스 문항을 옮긴 계산기. 틀린 답은 퀴즈의 오답노트로 갑니다.
- **풀이 게시판** — 절점법 팁. 공유 링크를 복사해 다른 브라우저에 담을 수 있습니다.
- **구조역학을 더 쉽게** — 사진 자료의 워런, 하우, 프랫, 그 외. 대표 사진을 누르면 같은 항목의 다른 사진이 열립니다.

부재를 잇는 중에 **우클릭**하면 자재를 고릅니다. 이미 있는 부재를 우클릭하면 그 부재의 자재가 바뀝니다.

인장 `+`는 파랑, 압축 `−`는 적색입니다. 기본 격자 간격은 0.5m이고, 힘은 N입니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 4187 포트에서 열립니다.

## GitHub Pages

`main`에 푸시하면 `.github/workflows/pages.yml`이 정적 사이트(`out`)를 GitHub Pages로 배포합니다. 저장소 설정에서 Pages 원본을 **GitHub Actions**로 한 번 지정해야 합니다.

프로젝트 페이지 주소는 `https://<사용자명>.github.io/truss-lab/` 입니다. 저장소 이름이 `truss-lab`이 아니면 그 이름이 경로가 됩니다. `username.github.io` 저장소에 올리면 루트에 배포됩니다.
